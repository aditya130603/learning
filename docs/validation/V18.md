# Adult UI and companion repair

The screenshot failures were caused by separate adult route renderers retaining the old child chooser and navy vocabulary theme, viewport-height quiz centering, and local inference flattening role-labelled dialogue into one user prompt. The native prompt also instructed the model to open with a day check-in on every request.

Adult Home, Learn, Review, Settings and age switching now use shared light surfaces, readable spacing and consistent navigation icons. Existing storage keys and profile history remain untouched. Conversation history is bounded visually so the editor remains reachable. The human companions and one-click verified model download remain.

Offline teaching cards are authored lessons, explicitly labelled. They explain a construction, offer an optional example to hide, and request a different situation. The existing conservative grammar evaluator gives immediate feedback through “Check my sentence”; unknown wording remains ungraded. This is separate from AI-generated conversation and awards no mastery for copying a card.

Native inference now uses system/user/model messages, excludes old role-labelled corrupt assistant turns, disables thinking explicitly, caps output at 64 tokens instead of 120, and cancels after 30 seconds rather than 90. The engine remains loaded between turns while on the speaking screen, but each turn still prefills a bounded history; this is not KV-cache reuse. Scripted dialogue, exact repeated responses, instruction echoes and direct input parrots are rejected before display or speech. These checks do not prove semantic correctness.

## Real model probe

`qwen-v18-host-probe.json` contains six actual Qwen3-0.6B int4 LiteRT-LM 0.18.1 outputs, with the new short system instruction, thinking disabled, deterministic sampling and two CPU threads. These are host measurements, not Android latency estimates. No training or weight updates were performed.

Manual assessment: greeting and “what are you doing” are responsive; the complaint response is superficially responsive but dismissive; the definition is broadly useful but has a weak follow-up; the grammar answer invents buying groceries; the work follow-up speaks as the learner. At least 3 of 6 still have material conversational/teaching defects. This small probe is not an accuracy benchmark. The offline model remains experimental and must not be represented as a reliable unrestricted teacher. Local grammar feedback covers validated patterns only. A stronger model or hosted service is still needed for dependable open-ended tutoring.

Physical-device verification is required for cold-load time, sustained generation latency, cancellation during native inference, microphone permission behavior, recognition quality, TTS voice selection/interruption, keyboard resize and download recovery. No emulator was launched.
